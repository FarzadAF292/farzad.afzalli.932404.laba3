## Описание

В данной лабораторной работе была продолжена разработка страницы из предыдущих лабораторных работ.

Основная цель работы — использование Flexbox и CSS Grid для построения адаптивного макета страницы.

В работе реализованы:

- Flexbox для блока «Startup Ideas»;
- 4 карточки стартапов;
- в каждой карточке указаны название, проблема и решение;
- CSS Grid для блока «Key Metrics»;
- метрики MAU, LTV и CAC;
- элемент `<meter>` для визуального отображения значений метрик;
- адаптивная вёрстка для desktop, tablet и mobile;
- медиа-запросы;
- адаптивная навигация;
- отсутствие горизонтальной прокрутки;
- сохранена стилистика предыдущих лабораторных работ.

## Адаптивность

Для разных размеров экрана реализованы разные варианты отображения:

- Desktop:
  - 4 карточки стартапов;
  - 3 блока метрик.

- Tablet:
  - 2 карточки стартапов;
  - 2 блока метрик.

- Mobile:
  - 1 карточка стартапа;
  - 1 блок метрик;
  - вертикальное навигационное меню.

## Используемые технологии

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
